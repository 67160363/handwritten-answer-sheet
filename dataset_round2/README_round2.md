# Dataset รอบ 2 — ตัวเลขผสม (มีเฉลย)

- 5 คน (W1–W5) × 10 แผ่น = 50 แผ่น = 1,500 คำตอบ, 8,703 ตัวเลข
- รอบนี้ทดลองเฉพาะหน้า 1 (ข้อ 1-30) ทุกแผ่น — เปลี่ยน PAGE_CYCLE ในสคริปต์เมื่อจะทำหน้า 2-3
- จำนวนเต็ม 1–6 หลัก (หน่วย–แสน), ทศนิยม 0/1/2/3 ตำแหน่ง
- จำนวนเต็มชิดขวา (ติดจุดทศนิยม), ทศนิยมชิดซ้าย, ช่องว่าง = เว้นว่าง
- `guides_W1.pdf` … `guides_W5.pdf` = ใบแนวของแต่ละคน (หน้าแรก = วิธีเขียน)
- `keys/W1_01_p1.csv` … = เฉลยต่อแผ่น (field,value) ใช้กับ `step5_predict.py --eval`
- `answer_keys_all.csv` = เฉลยรวม: writer, sheet, page, field, value, cells
  (`cells` 10 ตัวอักษร: `_`=ว่าง, `.`=ช่องจุด; ช่องรหัส 14 ตัวอักษรชิดซ้าย)
- รูปที่ถ่ายกลับมา: ชื่อ `W1_01_p1.jpg` วางที่ `data/mixed/`
- writer = W1..W5 ใช้แบ่ง train/test ตามคน
- สร้างใหม่: `python dataset_round2/make_mixed_keys.py` จากโฟลเดอร์โปรเจกต์ (seed 2026)
